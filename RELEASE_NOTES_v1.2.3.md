# Release Notes - v1.2.3

## 🌟 New Features & Enhancements

* **Planetary Nakshatras (Stars) Table:** Added a dedicated section under Planetary Positions to display precise Nakshatra data. It provides the Star name, the Pada (quarter) in the center, and the specific degrees and minutes traversed within that Nakshatra.
* **Ashtakavarga (SAV) Scores on South Charts:** The South Indian charts in both the Web and Mobile app now fully support displaying SAV scores, bringing them to feature parity with the North Indian charts.
* **Enhanced SAV Visuals:** The Ashtakavarga scores inside the charts have been updated to a vibrant Emerald Green (`#34d399`) across both Web and Mobile platforms to distinctively stand out against house numbers.
* **Refined Planet Indicators:** Standardized the status indicators for Retrograde `(R)` and Combust `(C)` planets for improved clarity in both Web and Mobile platforms.

## 🎨 UI/UX & Layout Optimizations

* **Compact Kundli Modal (Mobile App):** Extensively redesigned the Astrologer's Kundli Modal layout to drastically reduce all-around padding and utilize maximum vertical screen real-estate.
* **Integrated N/S Toggle:** The North/South chart layout buttons were previously overlapping and taking up too much vertical space. They have now been cleanly integrated as small toggle buttons `[N]` `[S]` directly into the chart header/tab row.
* **Realigned Planetary Positions:** Planetary degrees and Astakavarga (SAV) scores have been neatly realigned and moved to the middle of the planetary positions table row to make it much easier to read.
* **"Share" Button Optimization:** The "Share" button has been transitioned to an absolute floating position over the top corner of the chart, eliminating layout push and saving valuable screen height.

## 🐛 Bug Fixes

* **Astrologer App Crash Fix:** Resolved an issue causing errors when an Astrologer clicked on the Kundali icon in the live app.
* **South Chart Default:** Ensured the South Indian chart correctly honors the default selection based on user settings without rendering conflicts.
